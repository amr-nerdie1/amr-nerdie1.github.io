How I work

The same habits show up in every case study above.

Get the number right first

Every figure ties back to a source system and can be reproduced. Caveats are stated up front rather than found later. I prefer transparent, deterministic models that leadership can challenge line by line.

Prototype, prove, then ask

I build a working version on historical data, quantify the value, then make small, specific asks of engineering or IT. That gets AI work into production without long programs.

Ship in tests with stopping rules

Bounded experiments, staged rollouts and rollback gates. Decide in advance what result means stop, so we learn quickly and limit downside.

LLMs narrate, code calculates

In every agent I ship, numbers and decisions come from deterministic tools. Guardrails check each figure and claim before anyone sees it, untrusted text can't give instructions, and "not enough data" is an allowed answer. Prompts are published and the guardrails are red-teamed.
